# ENDLESS TRAIN — 끝없이 길어지는 기차

무료 브라우저 성장형 기차 게임.

**게임 플레이:** https://daehohohoho.github.io/traingame/

## 플레이 방법
- 열차가 달리는 동안 고철, 광석, 코인 등을 모읍니다.
- 새로운 객차를 구매하고 기차에 연결합니다.
- 발전칸 및 증폭칸을 활용해 생산 효율을 높입니다.
- 객차 위치를 바꿔 시너지 효과를 만듭니다.
- 정거장에서 보상을 골라 성장합니다.
- 게임 진행 상황은 해당 브라우저에 자동 저장됩니다.

## 무료 호스팅
GitHub Pages로 배포하는 정적 HTML 게임으로, 별도의 서버나 유료 API가 필요하지 않습니다.

## 배포
main 브랜치에 변경 사항이 반영되면 `.github/workflows/deploy.yml`이 자동 배포를 시도합니다.
저장소의 **Settings → Pages → Source**에서 `GitHub Actions`를 선택해 Pages를 활성화해야 합니다.

## 파일
- `index.html` : 게임 전체 소스 (HTML, CSS, JavaScript)
- `.github/workflows/deploy.yml` : 자동 배포
