# 빚쟁이 농부 — Debt Farmer

빚을 갚기 위해 직접 농사를 시작하고, 농장을 확장하며 후반에는 자동화를 구축하는 무료 웹 농장 게임 프로토타입.

**게임 실행:** https://daehohohoho.github.io/traingame/

## 플레이 방법
- WASD / 방향키: 이동
- 1~6: 괭이, 물뿌리개, 씨앗, 수확 도구
- 마우스로 가까운 땅 클릭: 작업
- Q: 상점 및 업그레이드
- E: 다음 날
- 상점에서 씨앗, 농지 확장, 스프링클러, 자동 파종기, 수확 드론 구입
- 수확물 판매와 빚 상환으로 진행
- 자동 저장: 현재 브라우저의 로컬 저장소

## 상태
초기 **프로토타입**입니다. 아트, 이동, 작물, 농장 자동화, 모바일 조작과 밸런스는 개발 중입니다. 외부 유료 서버나 API 없이 HTML/CSS/JavaScript로 작동합니다.

## GitHub Pages
정적 사이트는 `main` 브랜치 푸시 시 기존 `.github/workflows/deploy.yml`을 통해 배포됩니다. 게임 본체는 `index.html`에 CSS와 JavaScript를 포함하므로 외부 자산이 필요하지 않습니다.
