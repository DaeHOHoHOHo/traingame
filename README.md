# ENDLESS TRAIN v0.2 — 끝없이 길어지는 기차

**무료 플레이:** https://daehohohoho.github.io/traingame/

정적 웹페이지(HTML/CSS/JavaScript)로 만든 싱글 플레이 성장형 기차 게임. 별도 서버, 데이터베이스, 유료 API 없음.

## 조작
- 열차는 자동으로 이동하며 자원을 수집하고 생산합니다.
- 상점에서 객차를 구매하고 편성 메뉴에서 객차를 강화·이동·판매할 수 있습니다.
- 발전칸·공명칸·양자 복제칸은 인접한 객차의 생산을 증폭합니다.
- 선로 위의 보급품을 클릭해 추가 자원을 얻을 수 있습니다.
- 급행 운행은 일정 시간 동안 이동 및 생산 속도를 높입니다.
- 정거장마다 3개 보상 중 하나를 선택합니다.
- 연구소에서 생산 관련 영구 업그레이드를 구매하고, 운송 계약을 납품할 수 있습니다.
- 저장은 브라우저 localStorage에 자동으로 수행됩니다. 기기/브라우저 간 자동 동기화는 지원하지 않습니다.

## 수록 콘텐츠
- 객차 12종, 연구 6종, 지역 6종, 진행 목표 10개, 업적 8개, 반복 운송 계약.
- 전체 문서 스크롤 없이 화면에 맞춘 고정형 UI. 상점·편성·연구·기록은 내부 스크롤로 제공.
- 모바일에서는 하단 탭으로 원하는 관리 영역을 표시.
- v0.1 저장 데이터를 가능하면 자동으로 읽어 진행 상황을 계승합니다.

## 운영/배포
- `index.html`: 앱 진입점
- `style.css`: 반응형 레이아웃
- `game.js`: 클라이언트 게임 로직
- `.github/workflows/deploy.yml`: GitHub Pages 자동 배포

현재 **개발 중인 플레이 가능 버전(Early Access)**으로, 완성 상용 게임이 아닙니다.
