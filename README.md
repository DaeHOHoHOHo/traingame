# LAST TOWER · IDLE FORGE

무료 브라우저 기반 자동 전투 + 성장형 로그라이트 타워 게임입니다.

**플레이:** https://daehohohoho.github.io/traingame/

## 게임 방법

- 중앙 타워가 적을 자동으로 공격합니다. 전투용 액티브 스킬은 없습니다.
- 적 처치와 무인 채굴로 **고철(⬡)** 을 얻습니다.
- 화면 아래에서 **화력 / 연사 / 채굴 / 드론**을 즉시 구매합니다.
- **자동 구매 ON**을 선택하면 고철로 장비를 자동 강화합니다.
- 장비 구매 5회마다 타워가 추가 포신, 폭발탄, 연쇄 번개, 회전 칼날로 자동 진화합니다.
- 처치 수가 누적되면 보급 상자가 자동 개봉되고 추가 고철을 지급합니다.
- 매 웨이브 완료 시 무작위 로그라이트 능력 3개 중 하나를 선택할 수 있습니다.
- 보스와 웨이브 보상에서 **연구 데이터(◆)** 를 얻어 다음 판에도 유지되는 영구 연구를 구매합니다.
- 게임을 닫아도 최대 2시간 분량의 오프라인 연구 데이터가 정산됩니다. 오프라인 보상은 브라우저 로컬 시간에 의존합니다.
- 무한 웨이브 도전, 점수 및 최고 웨이브 기록을 지원합니다.

## 플레이 데이터

브라우저 `localStorage`를 사용합니다. 게임 기록은 사용 중인 브라우저/기기에만 저장되며, 브라우저 데이터를 삭제하거나 시크릿 모드로 실행하면 저장 내용이 유지되지 않을 수 있습니다. 초기 v1 게임의 최고 기록 데이터는 유지합니다.

## 배포

GitHub Pages 및 GitHub Actions를 사용하며 서버, 데이터베이스, 유료 API가 필요하지 않습니다. `main` 업데이트 시 배포 워크플로가 자동 실행됩니다.

- `index.html` : 전체 화면 UI
- `style.css` : 반응형 스타일
- `game.js` : 자동 전투, 자동 강화, 연구 및 오프라인 자원 계산
