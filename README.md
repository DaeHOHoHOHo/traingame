# 빚쟁이 농부 · Farm Story v0.3

캐릭터 없이 넓은 농장을 클릭·드래그로 관리하는 무료 픽셀아트 농장 게임입니다.

**플레이:** https://daehohohoho.github.io/traingame/

## 주요 기능

- 96×96 농장 맵, 농지 4방향 확장, 계절과 날씨
- 6종 작물 재배, 밭 갈기, 물주기, 수확, 창고 판매
- 빚 상환과 작업 도구의 범위 강화
- 마을 주문 게시판: 하루 두 건의 선택적 납품, 평판 보상
- 농산물 가공 공방: 주문에 필요한 재고를 제외한 잉여 작물 가공 판매
- 자동 관수, 파종, 수확, 복합 농장 관리 허브
- 자동 출하, 씨앗 정기배송, 자동 날짜 진행 및 일시정지
- 브라우저 로컬 자동 저장, 기존 저장 데이터 이어받기

## 조작

지도 드래그로 이동, 휠로 확대·축소, 클릭으로 작업, Shift+드래그로 연속 작업. Q로 상점 열기, E로 다음 날 진행.

## 배포

GitHub Pages 정적 호스팅으로 서버나 유료 API가 필요 없습니다. 사이트 본체는 `index.html`에 포함되어 있습니다. `main` 브랜치에서 기존 `.github/workflows/deploy.yml`을 통해 자동 배포됩니다.

개발 중인 프로토타입이므로 시각 효과, 콘텐츠 깊이와 밸런스는 계속 개선할 예정입니다.
