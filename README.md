# LAST TOWER — 타워 하나만 지켜라

**바로 플레이:** https://daehohohoho.github.io/traingame/

GitHub Pages에서 무료로 실행되는 한 화면 로그라이트 타워 디펜스 게임입니다.

## 플레이 방법
- **전투:** 타워가 중앙에서 자동으로 공격합니다.
- **목표:** 12개 웨이브를 돌파하며 타워를 지키세요. 4 / 8 / 12 웨이브에서 보스가 등장합니다.
- **강화:** 매 웨이브가 끝나면 3개의 무작위 강화 중 하나를 고르세요.
- **충격파:** 버튼 또는 스페이스바를 눌러 주변 적을 한 번에 밀어냅니다.
- **일시정지:** P 키 또는 상단 일시정지 버튼.
- **기록:** 최고 점수, 최고 웨이브는 내 브라우저에 저장됩니다.

## 주요 특징
- 22종의 강화: 트윈 포신, 회전 칼날, 폭발탄, 연쇄 번개, 지원 드론 등
- 12개 웨이브, 서로 다른 적 타입, 보스 3회
- PC·모바일 1화면 구성, 바깥 페이지 스크롤 없음
- 빌드 목록만 필요할 때 내부 스크롤
- 서버·유료 API·계정 없이 정적 HTML5 Canvas로 실행

## 배포
`.github/workflows/deploy.yml`이 `main` 브랜치에 반영되는 변경을 GitHub Pages로 자동 배포합니다.
