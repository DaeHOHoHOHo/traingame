# 빚쟁이 농부 — Debt Farmer

**무료 웹 농장 경영 게임** · 캐릭터 없는 탑다운 픽셀아트 농장 · 빚 상환 → 농지 확장 → 자동화.

▶ **[바로 플레이](https://daehohohoho.github.io/traingame/)**

## 플레이 방법
- 마우스/터치 드래그: 농장 지도 이동
- 마우스 휠, 화면 왼쪽 +/-: 확대 및 축소
- 밭 클릭: 선택한 도구로 경작, 파종, 물주기, 수확
- Shift + 마우스 드래그: 연속 작업
- 도구막대 또는 숫자키 1~9: 도구 변경
- 상점 버튼 또는 Q: 씨앗, 도구, 토지, 자동화 장비 구매
- 다음 날 버튼 또는 E: 작물 성장과 자동화 진행
- 수확물 모두 판매: 창고 작물을 현금화
- 빚 상환: 초반 빚 갚기

## 구현 내용
- 96×96 규모의 타일 지도와 카메라 이동, 4방향 농지 확장
- 경작/물주기/심기/수확, 작물 6종, 일부 작물의 반복 수확
- 계절과 날씨 변화, 수확 기념 보상
- 스프링클러 · 자동 파종기 · 수확 드론 (설치 위치에 따른 작동 범위)
- 자동 출하 · 정기 씨앗 공급 · 자동 날짜 진행 (후반 해금)
- 브라우저 자동 저장. 이전 프로토타입 저장 데이터 이전 시도
- GitHub Pages용 정적 HTML 게임. **서버 및 유료 API 불필요**

## 개발 상태
현재 개발 중인 플레이 가능한 프로토타입입니다. 완성된 상용 게임의 콘텐츠·아트·밸런스 수준은 아닙니다.
