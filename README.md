# DEEP SALVAGE — 심해 인양 계약

**무료로 플레이하기:** https://daehohohoho.github.io/traingame/

기존 LAST TOWER / ENDLESS TRAIN을 대체하는 2D 웹 로그라이트 인크리멘탈 게임입니다.

## 게임 방법

- **누르고 있기:** 크레인이 바닷속으로 내려가며 가까운 물건을 수집합니다.
- **손 떼기:** 크레인이 올라와 화물을 매각합니다. 집게가 가득 차면 자동으로 인양합니다.
- **PC 키보드:** `←`, `→`로 위치를 조정하고 `Space`를 눌러 하강, 떼면 인양합니다.
- **계약 완료:** 제한 시간 안에 목표 금액에 도달하면 특수 능력 3개 중 하나를 선택합니다.
- **업그레이드:** 크레딧으로 모터, 화물 용량, 희귀 탐지, 전자석, 산소, 판매 단가를 강화합니다.
- **성장:** 장비 업그레이드와 보유 크레딧은 브라우저에 저장됩니다. 한 탐사의 특수 능력은 새 탐사에서 초기화됩니다.
- **목표:** 5개 계약을 완수하거나 이후 무한 계약에 도전하세요.

## 기술 / 운영

HTML + CSS + JavaScript Canvas, 외부 자원 또는 유료 API 없음.
GitHub Pages 정적 사이트로 운영하며 계정 없이 플레이할 수 있습니다.
저장은 브라우저 LocalStorage를 사용하므로 다른 기기와 동기화되지 않습니다.

## 구조

- `index.html`: 화면 구조
- `style.css`: 반응형 단일 화면 인터페이스
- `game.js`: 게임 플레이, 인양·상점·특수 강화·저장 로직
- `.github/workflows/deploy.yml`: GitHub Pages 자동 배포
